Sample Types of Assessment for Diagnosis MCQs with answers

Sample MCQ #1

In a 2x2 table, sensitivity is calculated as?

ATrue positives / (true positives + false positives)
BTrue positives / (true positives + false negatives)
CTrue negatives / (true negatives + false positives)
DTrue positives / (true positives + true negatives)
Show Answer & Explanation ▾
✓ Correct Answer: B. True positives / (true positives + false negatives)

Sensitivity is the proportion of truly diseased people the test correctly identifies: true positives divided by all diseased subjects (true positives + false negatives).

Sample MCQ #2

How is specificity calculated?

ATrue negatives / (true positives + false negatives)
BTrue negatives / (true negatives + false positives)
CTrue positives / (true positives + false positives)
DFalse negatives / (false negatives + true negatives)
Show Answer & Explanation ▾
✓ Correct Answer: B. True negatives / (true negatives + false positives)

Specificity is the proportion of truly non-diseased people the test correctly identifies: true negatives divided by all non-diseased subjects (true negatives + false positives).

Sample MCQ #3

If disease prevalence in the tested population falls, the positive predictive value of the same test will?

ARise
BFall
CStay the same
DBecome equal to sensitivity
Show Answer & Explanation ▾
✓ Correct Answer: B. Fall

Predictive values depend on prevalence, unlike sensitivity and specificity. As prevalence falls, false positives make up a larger share of all positive results, so the positive predictive value falls.

Sample MCQ #4

A test with 80% sensitivity and 90% specificity has a positive likelihood ratio of?

A2
B4
C8
D10
Show Answer & Explanation ▾
✓ Correct Answer: C. 8

Positive likelihood ratio = sensitivity / (1 - specificity) = 0.80 / 0.10 = 8. An LR+ above 10 is strong evidence for disease, 5-10 moderate, and 2-5 weak.

Sample MCQ #5

An ROC curve with an area under the curve (AUC) of 0.5 indicates?

AExcellent discrimination
BNo better than chance
C50% sensitivity at every threshold
DAn invalid test
Show Answer & Explanation ▾
✓ Correct Answer: B. No better than chance

An AUC of 0.5 is the diagonal line of no discrimination, equivalent to chance. An AUC of 1.0 is perfect discrimination. Higher AUC means better overall ability to distinguish diseased from non-diseased across thresholds.

Sample MCQ #6

A new test is validated against the best available existing diagnostic method. This comparator is called the?

AIndex test
BReference (gold) standard
CScreening test
DSurrogate marker
Show Answer & Explanation ▾
✓ Correct Answer: B. Reference (gold) standard

The reference standard is the best available method for establishing true disease status. When it is imperfect, misclassification of the reference itself distorts the new test's apparent accuracy, a problem known as verification bias.

Sample MCQ #7

Screening appears to prolong survival only because diagnosis was made earlier, without changing the time of death. This is?

ALead-time bias
BLength-time bias
CSelection bias
DRecall bias
Show Answer & Explanation ▾
✓ Correct Answer: A. Lead-time bias

Lead-time bias is the apparent survival gain from earlier diagnosis when the time of death is unchanged. Length-time bias is different: screening preferentially detects slow-progressing cases, which have better prognosis anyway.

Sample MCQ #8

Agreement between two raters beyond what chance alone would produce is quantified by?

APearson correlation
BCohen kappa
COdds ratio
DCronbach alpha
Show Answer & Explanation ▾
✓ Correct Answer: B. Cohen kappa

Cohen kappa measures inter-rater agreement corrected for chance agreement: 1 is perfect agreement and 0 is agreement no better than chance. It is the standard measure for categorical diagnostic assessments.
